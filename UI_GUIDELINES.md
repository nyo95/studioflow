🎨 Studioflow Visual DNA
Context: "Studioflow" Design System
To achieve the "Studioflow" look requested in PRD 3, follow these specific UI constraints:

Layout Hierarchy: A dual-sidebar system.

Outer Sidebar: Ultra-thin (approx. 64px), icon-only, dark or neutral slate background.

Inner Sidebar: Standard width, clean white/slate-50 background, containing nested navigation.

Typography Mix:

Serif (Lora): Use for Page Titles, Project Names, and Main Headings to give an "Editorial/Premium" feel.

Sans-serif (Inter/Geist): Use for all functional UI elements (buttons, inputs, table data, sidebar labels).

Surface & Borders:

Avoid heavy shadows. Use subtle 1px borders (border-slate-200).

Main content area should use a very light grey background (bg-slate-50) to make white cards/tables "pop".

Table Style: Clean rows with generous padding. Header rows should be subtle but clear, using Lora for category group separators.
